# VOXLATAM (100% Gratis · IA en el Dispositivo)

Aplicación Android de transcripción inteligente, separación automática de hablantes (`Hablante 1`, `Hablante 2`...) y detección acústica de tono de voz con diccionarios regionales latinoamericanos.

## Características
- **0% APIs de pago / Sin cuotas:** Corre modelos Whisper ONNX directamente en el procesador del teléfono.
- **Modo Offline:** Tras descargar el modelo la primera vez, funciona incluso en modo avión.
- **Personalización total:** Negro AMOLED puro (`#000000`), Modo Claro y selector libre de colores.
